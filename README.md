# ONG-REASSOCIA-PROJETO-DE-EXTENS-O-
Será desenvolvido um site institucional para a ONG Reassocia, utilizando Python e banco de dados, com o objetivo de apresentar e organizar as informações dos projetos e ações sociais desenvolvidos pela organização. O sistema permitirá cadastrar, consultar e atualizar informações dos projetos, facilitando o acesso da comunidade .
